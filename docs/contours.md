# 可切换等高线

地图设置中开启“等高线”，默认关闭。彩色底图用深紫灰与细浅色描边，
灰度底图用浅金色。低、中、高缩放依次显示 10 / 5 / 2 米，50 米主线加粗。
等高距不是实际地形精度保证。只作地形参考，不修改射击诸元。

三张地图的显示平移默认向东27米、向北27米，依据用户局部目视对齐结果，
不是上游标定或实测地形精度证明。已保存的手动偏移优先，数值是总偏移，
不额外累加默认值。可选择“恢复默认 +27 / +27m”或“当前地图归零”。
底图、目标坐标、高程查询及弹道计算不受此显示校准影响。

按视口加载 gzip JSON 分块，同时最多 4 个请求，缓存最多 160 块。
需要浏览器支持 DecompressionStream；不支持或加载失败时保留正常底图与火控。
当前未标注绝对海拔，未包含试验中的简化地图或路网模型。

派生数据及来源见 public/contours/NOTICE.md。
