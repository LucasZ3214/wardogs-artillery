# 本地版与静态版同步规则

本项目同时维护两个版本：

- Windows 本地版：`G:\Wardogs`
- GitHub Pages 静态版：`G:\Wardogs\static-site`

## 必须双向同步的功能

以下功能属于共享火控核心；任一版本修改后，都必须检查并同步另一版本：

- L81、SPH-2 射表、有效射程及高低弹道插值
- 方位、距离和地图坐标换算
- 地图边界、地标及瓦片坐标
- Canvas 绘制、准星、射程圈、网格和 Pointer Events 触控状态机
- 目标、落点、末端调整半径、迭代虚拟瞄准点和撤销逻辑
- 目标历史的 `schema: 1 / settings / targets` JSON 格式
- 响应式布局、iPad safe-area、全屏和无障碍改进

## 版本专属功能

仅 Windows 本地版维护 FastAPI、SQLite、LAN 配对、WebSocket、PyQt6 悬浮窗、Qt TTS 和本地地图缓存。

仅静态版维护 GitHub Pages 工作流、社区 CDN 地图加载、`localStorage` 和作战区高程派生包。

## 开发记录要求

每项本地版新功能或修复必须在变更说明中写明：

1. 是否适用于静态版；
2. 若适用，是否已经同步；
3. 若无需同步，说明版本边界原因；
4. 若暂缓同步，创建可追踪事项并附链接或编号。

静态版的 Pull Request 模板包含相同检查项。共享逻辑应尽量保持函数签名、数据字段和测试用例一致，避免两个版本产生不可见的算法分叉。
