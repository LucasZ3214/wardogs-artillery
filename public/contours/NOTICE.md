# Terrain contours

Derived offline from the community wardogs-calculator Terrain3D assets-v1
2-meter horizontal samples. Source: https://github.com/apollyon-sys/wardogs-calculator

Only playable bounds are included. Display intervals: 10m, 5m, 2m; index 50m.
Line simplification tolerance: 0.75m. These intervals do not assert vertical
accuracy. No absolute altitude labels; data has an offset datum. Informational
only; contours do not alter firing calculations. Third-party map/terrain data
is not covered by the application code license. Not an official game tool.
